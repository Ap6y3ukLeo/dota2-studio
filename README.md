# Dota 2 Studio

GUI-утилита для монтажа стримов Dota 2 на Windows. Один файл, никаких сервисов: всё считается локально через `ffmpeg`.

## Что умеет

| Вкладка | Что делает |
|---|---|
| **1. Монтаж матча / Серии** | Собирает финальный ролик из VOD: тизер-хук, драфт, падение трона, все убийства. Убийства ищутся по смене счёта в верхней панели, а не по звуку. Плавные склейки, заглушка матов, закрытие баннера картинкой, вставка-заставка Telegram-канала. |
| **2. Реакции / Кейсы / IRL** | Монтаж видео с реакциями, вырезание донатов и пауз. |
| **3. Топ клипы за месяц** | Скачивает клипы с Twitch через `yt-dlp`, ставит титр с названием, закрывает плашку букмекера картинкой и склеивает в подборку. |
| **4. Нарезка Shorts (9:16)** | Режет вертикальные шортсы: вебка сверху, игра снизу. Умеет вставлять рекламный ролик по хромакею — с паузой видео и звука. |
| **5. Заглушение матов** | Распознаёт речь через `faster-whisper` и глушит слова из словаря. |
| **6. Закрыть баннер PNG** | Перекрывает участок кадра картинкой (например, логотип спонсора). |
| **7. Вставка рекламы** | Вставляет рекламный MP4 в готовое видео на выбранном тайминге. Плюс автоматическая вставка на 01:00 прямо во время монтажа — но только если стример в этот момент молчит. |
| **8. Описание (DeepSeek)** | Расшифровывает готовый ролик и просит DeepSeek написать заголовок, описание, хэштеги и главы, а также 3 варианта поста в Telegram в стиле канала. Если рядом лежит файл таймкодов от монтажа или сборника — берёт реальные границы глав оттуда, а модель только придумывает названия. Ключ: поле в программе или `DEEPSEEK_API_KEY`. |

Длительность драфта (пиков) в начале каждой карты задаётся в поле **«Драфт (пики), мин»** — по умолчанию 1.5 мин (90 с), значение можно задать отдельно для каждой карты.

## Установка

1. [Python 3.10+](https://www.python.org/downloads/).
2. Зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Положить **`ffmpeg.exe`** рядом со скриптом (в репозиторий не входит — ~100 МБ, качается с [ffmpeg.org](https://ffmpeg.org/download.html)).

## Запуск

```bash
python vod_cutter_gui.py
```

Настройки (пути, галочки, позиции баннеров) сохраняются в `studio_config.json` рядом со скриптом — файл создаётся сам.

## Зависимости по желанию

* `faster-whisper` — цензура матов и дорезка кусков, когда стример не договорил. Без него программа работает, эти шаги пропускаются.
* `yt-dlp` — только для вкладки с клипами Twitch.

## Временные файлы и GPU

Временные файлы по умолчанию пишутся в `D:\Dota2StudioTemp` (папка создаётся сама). Папку можно выбрать прямо в окне программы — поле **«Временные файлы»** внизу (кнопки «Выбрать...» и «Открыть»). Также путь можно задать ключом `"temp_dir"` в `studio_config.json` или переменной окружения `DOTA2STUDIO_TEMP`. Если диск недоступен, используется системный TEMP.

Если в системе есть Intel GPU с Quick Sync, видео кодируется через `h264_qsv` — нагрузка уходит на медиаблок видеокарты, CPU остаётся свободным для игры. Проверка автоматическая перед первым рендером. Отключить: `"use_gpu_qsv": false` в `studio_config.json` или `set DOTA2STUDIO_NO_GPU=1`. Без QSV используется прежний `libx264`.

## Как ищутся убийства

Детектор читает только полосу со счётом в верхней панели (4 кадра/с через `ffmpeg`), переводит её в маску белых цифр и ждёт устойчивого шага: цифры поменялись и дальше стоят на месте. Движение игры за полупрозрачной панелью и анимированные портреты героев отсекаются.

Координаты рассчитаны на стандартный HUD Dota 2 в 16:9 (1920x1080 / 1280x720). Если счёт не находится, в логе будет `Смен счёта: 0`.

## Требования

* Windows (используется `tkinter`, `os.startfile`)
* Python 3.10+
* `ffmpeg.exe` рядом со скриптом
